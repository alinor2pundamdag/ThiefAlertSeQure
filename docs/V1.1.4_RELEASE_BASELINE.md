## 2. Release tag, asset and updater contract

The official release tag for this exact version is:

```text
v1.1.4_Developer_Alinor
```

The signed APK asset name is:

```text
ThiefAlertSeQure-v1.1.4_Developer_Alinor-release.apk
```

The checksum sidecar is the APK filename plus `.sha256`.

The release workflow already requires the pushed tag to equal `v${appVersionName}`, so the suffix is part of the exact tag. The workflow trigger accepts `v*` tags. The in-app updater was corrected to parse this approved suffix while retaining compatibility with legacy numeric tags such as `v1.1.3`. It derives the expected APK versionName and asset filename from the exact tag, then continues to enforce package identity, strictly increasing versionCode, SHA-256, and the pinned production signer.

Only the suffix `_Developer_Alinor` is accepted by the new tag parser; arbitrary suffixes and malformed tags are rejected by unit tests.
