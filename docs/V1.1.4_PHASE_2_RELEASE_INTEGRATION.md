## 4. Release workflow review

The candidate's official release workflow was inspected. It is fail-closed on the following conditions:

1. A pushed release tag must match `v${appVersionName}`.
2. The tagged commit must already be an ancestor of `main`.
3. All four owner-controlled signing secrets must be present.
4. The decoded keystore must match the pinned production certificate SHA-256.
5. versionCode must be greater than the latest official release.
6. APK package, versionCode, versionName, signer, and SHA-256 are verified before publication.
7. Manual signed preflight is restricted to `main` and uploads a short-retention artifact without publishing a GitHub Release.
