## 7. Distribution and source-licensing decisions

- The production manifest currently declares REQUEST_INSTALL_PACKAGES, and the in-app updater performs a user-initiated self-update through Android Package Installer. Current Google Play policy says this permission may not be used for app self-updates except for device-management purposes. If Google Play distribution is intended, the current updater/permission needs a separate Play-compliant design or build variant; do not assume optional Device Owner mode automatically qualifies. See https://support.google.com/googleplay/android-developer/answer/12085295 and https://support.google.com/googleplay/android-developer/answer/18265346.
- The repository is public and its LICENSE is Apache-2.0. R8 does not conceal the already-public source. Changing repository visibility now would not revoke public copies or rights already granted under the license. No visibility or license change was made.
- Owner decision required: confirm whether v1.1.4 is distributed only as a direct GitHub APK or is also intended for Google Play. The manifest permission was not changed pending this decision.

## 11. v1.1.4-only URL validation hardening patch

- Only the reusable URL validation rule was adapted from later review evidence; no v1.1.5 version identity, release logic, or product feature was copied.
- AppUpdatePolicy.isAllowedHttpsUrl() validates scheme, exact approved GitHub hostname, standard HTTPS port (implicit default or 443), and absence of URL user-info.
- AppUpdateManager.openHttps() applies this rule before every connection, including every manually followed redirect.
- JVM regression tests cover valid GitHub hosts, explicit port 443, uppercase hostname, HTTP rejection, lookalike hosts, embedded user-info, non-standard ports, and malformed URLs.
- The patch is source-committed on the v1.1.4 candidate. Final exact-head Android CI and CodeQL results are required before marking this patch verified.
